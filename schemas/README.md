# Baspin Schemas

Machine-readable contracts for structured Baspin objects.

Current schema:
- `okf-project.schema.json` — initial project-level OKF contract

Future schemas may cover:
- project
- department
- question
- answer
- evidence
- requirement
- conflict
- approval
- agent outputs
- readiness result

All agent-generated structured outputs should eventually validate against explicit schemas before entering deterministic workflow logic.
