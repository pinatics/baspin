# Baspin Web

Business Analyst and stakeholder-facing web application.

## MVP Screens

1. Project Dashboard
2. Department Status
3. Questions & Responses
4. Evidence & Provenance
5. Conflicts / Clarifications
6. Department Approval
7. Cross-Department Review
8. OKF Preview
9. Project Readiness Gate

The UI should make uncertainty visible. A user must be able to distinguish approved, pending, disputed, superseded, and AI-generated information at a glance.
